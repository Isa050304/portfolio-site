# Isabel Contreras Portfolio

Static portfolio site prepared for GitHub Pages and the custom domain routing already used by the project.

## Main structure

- `/` — Home
- `/work` — all portfolio work and category filters
- `/about` — About + resume
- `/contact` — contact page
- `/work/<project-slug>` — clean project URLs

## Project images

The images referenced by the website are stored in:

`assets/projects/web/`

See `README-LATEST-PROJECT-IMAGES.txt` for the current filename map.

Long website screenshots for Numode Delivery and Transylvanian Traditions are displayed inside a scrollable desktop-style browser frame. Regular artwork uses `object-fit: contain` with a safe area on all four sides so the work remains visible at different proportions.

Project sliders support previous/next controls, keyboard arrows and horizontal touch swipes on phones/tablets. Website screenshot frames keep vertical touch scrolling available.

## Before / after sections

Desktop uses a draggable comparison divider. On phones, before/after content switches to separate stacked panels so each design has enough room to be read.
