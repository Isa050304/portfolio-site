# Isabel Contreras Portfolio

## Add these existing assets

Place your real files in the following paths:

- `assets/logos/logo-wordmark.svg`
- `assets/artwork/identity-artwork.png`
- `assets/artwork/about-portrait.jpg`
- `assets/projects/football-poster.png`
- `assets/projects/nexa-booklet-cover.png`
- `assets/projects/movie-poster.png`
- `assets/yarn/yarn-ball.svg`
- `assets/ui/favicon.png`
- `assets/resume/isabel-contreras-resume.pdf`

## Local preview

Open the folder in VS Code and use Live Server.

## GitHub Pages

The project uses relative links, so it works from a GitHub Pages project subfolder.
