V20 ARROW SYSTEM

All directional arrows now use the same asset:
assets/icons/arrow.svg

The SVG is rendered through a CSS mask, so a black source SVG is automatically displayed in the portfolio accent pink (#c43452).

You can replace assets/icons/arrow.svg with your exact arrow file without changing any HTML, CSS, or JavaScript. Keep the same filename.

Directions are created by rotation:
- right: 0deg
- left: 180deg
- up: -90deg
- up-right: -45deg

The same arrow is used for:
- project slider previous/next controls
- Work 'View project' links
- project resource links
- Next project cards
- Back to top
- Before/After comparison grip

Filled red CTA buttons use the same SVG shape in white only where needed for contrast.
