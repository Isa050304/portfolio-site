V13 scroll and control fixes

- Scrollable website and Staff Portal frames now own trackpad/finger panning without competing with carousel navigation.
- Two-finger slide navigation is disabled whenever the active project slide is a scrollable website/app screen.
- Staff Portal desktop screenshots fit the browser frame with a small even side margin.
- Staff Portal mobile screenshots use a modest 118% zoom so interface text remains readable and can be panned horizontally/vertically.
- All website/app viewers use native iOS momentum scrolling.
- Carousel arrow icons are geometrically centered and remain CSS-drawn (no emoji glyphs).
- Existing touch swipe outside scrollable website/app frames remains available.
